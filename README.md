# Лекси

Интерактивный курс греческого алфавита, чтения и чисел. Сайт работает без сервера и публикуется через GitHub Pages.

Прогресс хранится в cookies браузера. Для озвучивания используется встроенный Speech Synthesis API с греческим голосом, если он установлен в системе.

## Запуск локально

Откройте `index.html` в браузере или запустите любой статический сервер в корне проекта.
